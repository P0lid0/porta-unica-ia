# Manual de instalação — Orion DataMask v3

- Requisitos: z/OS 2.3 ou superior, 2 GB de espaço em disco para as bibliotecas de carga.
- A instalação é feita via SMP/E, com JCL de exemplo fornecido no pacote.
- Suporte técnico: telefone e e-mail em horário comercial.
